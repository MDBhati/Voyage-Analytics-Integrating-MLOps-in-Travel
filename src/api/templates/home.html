Voyage Analytics API

Travel data analytics, flight price prediction, and hotel recommendations — served as a production-style ML API.

Interactive API docs ReDoc Prometheus metrics About (JSON)

Project objective

Build an end-to-end analytics stack that ingests travel datasets, trains models, tracks experiments, and exposes predictions through APIs and dashboards.

Flight price prediction

Regression model trained on historical routes. Send origin, destination, flight class, agency, duration, and distance to estimate price.

Hotel recommendations

Content-based similarity over hotel location and name. Available via the Streamlit app using compact artifacts in artifacts/models/.

Gender classification

Classify traveler gender from name, company, and age using a trained classifier on the users dataset.

MLOps capabilities

  • MLflow experiment tracking
  • Airflow training DAGs
  • Docker & Kubernetes deployment
  • Drift detection & structured logging
